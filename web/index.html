Вопросы

В каком браузере лучше работать?

Лучше всего — на компьютере в Chrome или Microsoft Edge. В Edge голоса Microsoft работают напрямую и быстрее. На телефоне тоже работает, но сборка ролика идёт медленнее.

Это то же самое, что программа для ПК?

Да, тот же интерфейс и те же функции. Ролик собирается прямо на вашем устройстве, в браузере — на сервер ничего не загружается.

Сколько стоит?

Первый ролик — бесплатно. Дальше — лицензия, как у программы для ПК. Ключ работает на одном ПК в программе и в одном браузере.

Куда сохраняется готовый ролик?

Нажмите «Скачать ролик» — файл сохранится в «Загрузки». Ключи и настройки браузер запоминает сам.

Нужно ли скачивать что-то тяжёлое?

Нет. Только для отдельных функций браузер один раз скачает модель — голос Piper (~63 МБ) или распознавание речи «Из видео». Дальше они берутся из памяти браузера.

Нужна программа для Windows? Скачать с GitHub или из Microsoft Store
